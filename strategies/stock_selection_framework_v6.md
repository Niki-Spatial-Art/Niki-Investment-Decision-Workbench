# A股选股框架 v6：技术面 + 基本面（财务 + 资金面）结合

> 版本：v6（2026-09-03 升级，权重经 IC 实证校准）
> 核心变化：**新增两个「资金面」信号**（融资余额变化 + 业绩预告），并对全部因子做历史回测，砍无效、反转反向。
> 财务/资金面因子满分经实证校准为 **33 分**，综合分 = 技术 100 + 财务 33 = **满分 133**。

## 一、v5 → v6 改了什么

| 维度 | v5（技术 + 财务） | v6（技术 + 财务 + 资金面，实证校准） |
|---|---|---|
| 财务因子满分 | 30 分 | **33 分**（营收10 + 融资10 + 预告10 + 龙虎榜3） |
| 无效因子剔除 | 净利增速/筹码集中各 10 分 | **降权归零**（实证 IC≈0，仅展示） |
| 资金面维度 | 无 | 融资余额变化 10 + 业绩预告 10 |
| 综合满分 | 130 | **133** |
| 排序依据 | 技术 + 财务 | 技术 + 财务 + 资金面 |

**为什么加这两个因子？（v6 初版动机）**

当前最大短板不是"因子不够多"，而是**缺资金面信号**。财务指标是"后视镜"（滞后 1~2 个月），而资金面是"实时镜"（反映当下真金白银的进出）：

- **融资余额**：杠杆资金是最聪明的钱之一，融资余额持续上升 = 场内资金加杠杆看多，短期方向性强。
- **业绩预告**：比正式财报**提前 1~2 个月**释放业绩信号，是抓"业绩超预期"的黄金窗口。

> ⚠️ **但实证回测推翻了上述两个"直觉"**（见第九节）：融资余额、业绩预告都是**反向指标**，已反转；净利增速、筹码集中**无效**已归零。v6 最终只保留技术面 + 营收增速（弱有效）+ 两个反向资金面因子。

## 二、资金面因子设计（新增，各 10 分）

### 因子E 融资余额变化（10分）—— ⚠️ 已实证反转（反向指标）

> **实证结论（2026-09-03，`backtest_factors.py` 回测 200 只 / 2479 对样本）：**
> 融资余额变化率是**反向指标**。IC（未来5/10/20日）= -0.062/-0.055/-0.054，t 值均 < -2.7（显著反向）。
> 分层回测：融资余额暴增的 Q5 档未来20日 **-0.58% 胜率仅 43.3%（最差）**，融资流出的 Q1 档反而抗跌。
> **含义：融资余额上升 = 杠杆资金高位追涨 = 后续踩踏**（散户情绪反向，与梅森"不追高"纪律同源）。

| 指标 | 数据源 | 打分规则（反转后） |
|---|---|---|
| 融资余额近20日变化 | `get_margin_detail` 的 `BORROW_MONEY_BALANCE` | 暴增 >15% 得0、>8% 得2、>3% 得4、>-5% 得6、>-15% 得8、更低得10 |

- 融资余额**回落（去杠杆）加分，暴增（追涨）扣分**。
- 注意：用「融资余额变化」而非「融资买入额」，因余额是存量，更能反映资金的持续态度。
- ⚠️ 选择性偏差：大量非两融标的返回空数据，融资因子天然只覆盖两融标的。

### 因子F 业绩预告（10分）—— ⚠️ 已实证反转（反向指标）

> **实证结论（2026-09-03，`backtest_forecast.py` 事件研究 300 只 / 1275 事件，控制沪深300 beta 后的超额收益）：**
> 预增/扭亏公告后20日超额 +3.55%（胜率53.2% ≈ 随机）→ **利好"见光死"，无正向预测力**；
> 预减/亏损公告后20日超额 +5.27%（胜率70.1%）→ **利空出尽，困境反转**。
> **故反转打分：预减/首亏加分，预增/略增扣分**（不再依赖增速大小）。

| 指标 | 数据源 | 打分规则（反转后） |
|---|---|---|
| 最新业绩预告类型 | `get_profit_notice` 的 `P_TYPECODE` | 预亏/首亏/续亏 10、预减/略减 7、其他/扭亏 3、预增/略增/续盈 0 |

- **P_TYPECODE 对照**：1=预亏 2=首亏 5=续亏（→10分）；6=预减 7/9=略减（→7分）；3=略增 10/13=预增 11=续盈 12=续增（→0分）；4=扭亏 及其他（→3分）。
- 反转打分**只看类型，不看增速**：增速的"扭亏/低基数失真"问题（如荣昌生物 1145% 扭亏型）在此框架下自然消解——因为预增无论如何都不加分。

实测踩坑案例（2026-09-03，v6 初版误判，现已修正）：
- 荣昌生物预告增速 **1145.4%**，但 `P_NET_PARENT_FIRM=-44956`（去年亏损），是**扭亏型**失真，初版错误重奖为 8 分。
- 星宸科技预告 **617.1%**、海思科 **544.3%**，去年同期净利仅 1.2 亿左右，是**低基数型**失真，初版错误封顶 7 分。
- 这些"假高增长"在反转框架下统一归为"预增=0分"，不再被奖励。

## 四、资金面接口关键字段（实测确认）

### 1. 融资融券明细 `get_margin_detail(codes, is_local=False)` → `dict{code: DataFrame}`
```
TRADE_DATE              交易日期
BORROW_MONEY_BALANCE    融资余额（⭐ 用这个，存量指标）
PURCH_WITH_BORROW_MONEY 融资买入额（当日流量）
REPAYMENT_OF_BORROW_MONEY 融资偿还额
MARGIN_TRADE_BALANCE    两融余额
SEC_LENDING_BALANCE     融券余额
```

### 2. 业绩预告 `get_profit_notice(codes, is_local=False)` → DataFrame
```
P_TYPECODE        预告类型（4=扭亏/10=预增/等）
REPORTING_PERIOD  预告的报告期
ANN_DATE          公告日
P_CHANGE_MAX      净利增速上限（%）
P_CHANGE_MIN      净利增速下限（%）
NET_PROFIT_MAX    预告净利上限（元）
NET_PROFIT_MIN    预告净利下限（元）
P_NET_PARENT_FIRM 去年同期归母净利（⭐ 判断低基数/扭亏用）
```

### 3. 融资融券汇总 `get_margin_summary(is_local=False)` —— ⚠️ 市场级，非个股
返回沪深北交易所的融资融券**总量**（`SUM_*` 字段），是**大盘资金面**指标，不能做个股因子。个股两融必须用 `get_margin_detail`。

## 五、关键坑（踩过，务必记住）

1. **`get_margin_summary` 没有 code_list 参数**：签名是 `(self, local_path, is_local, **kwargs)`，传 code 会报 TypeError。它是市场汇总，做个股因子要用 `get_margin_detail`。
2. **`get_margin_detail` 返回 dict**（不是 DataFrame）：`{code: DataFrame}`，需要按 dict 遍历，每个 value 是该股的两融历史。
3. **业绩预告增速也会失真**：预告增速同样存在扭亏/低基数陷阱，必须用 `P_NET_PARENT_FIRM`（去年同期净利）做性质判断，否则 1145% 这种扭亏型假高增长会被错误重奖。
4. **预告取最新一条**：同一票有多条历史预告，按 `ANN_DATE` 排序取最新，避免拿到过期预告。

## 九、因子权重实证化（2026-09-03 新增，关键成果）

> 原"下一步方向"第 1 条已落地：用历史数据回测各因子 IC / 分层收益，砍无效因子、反转反向因子。

产出三个可复用回测脚本：

| 脚本 | 方法 | 结论 |
|---|---|---|
| `backtest_factors.py` | IC 检验 + 分层回测（时间序列因子） | **融资余额因子反向，已反转** |
| `backtest_forecast.py` | 事件研究法（超额收益版，事件型因子） | **业绩预告因子反向，已反转** |
| `backtest_financial.py` | 事件研究 + IC（公告日对齐，减沪深300） | 净利/筹码无效、营收弱有效 |

### 已实证：融资余额因子是反向指标（v6 已修正）
- IC（未来5/10/20日）= **-0.062/-0.055/-0.054**，t 值 -3.09/-2.75/-2.71，统计显著反向。
- 分层：Q5（融资暴增）未来20日 -0.58% 胜率43.3%（最差）；Q1（融资流出）抗跌。
- 已把因子E 打分方向反转（commit `c5b0d45`）。

### 已实证：业绩预告因子"见光死"（v6 已修正，commit `3cbaa33`）
- 事件研究（300 只 / 近3年 / 1275 事件，控制沪深300 beta 后的超额收益）：
  - 预增/扭亏公告后：20日超额 +3.55%（胜率仅 53.2%，接近随机）。
  - 预减/亏损公告后：20日超额 **+5.27% 胜率 70.1%**（"利空出尽" + 困境反转）。
- 结论：预增无正向预测力（利好兑现即下跌），预减反而更强。因子F 已反转。

  - **净利增速**：IC 未来20日 +0.009 / 60日 +0.005 → **纯噪音，无效** → 已降权归零（仅展示）。
  - **筹码集中（股东户数环比）**：IC 20日 -0.025 / 60日 -0.001 → **噪音，无效** → 已降权归零（仅展示）。
  - **营收增速**：IC 60日 **+0.031** → **弱有效**（唯一过线的老财务因子）→ 升权 5→10 分。
- 龙虎榜因子未单独实证，保守从 5 分降至 3 分。

### 六因子全实证规律（重要）
> **纯基本面/资金面因子在 A 股短线（20-60日）选股都不可靠**：资金面（融资/预告）是反向的，财务面（净利/筹码）是无效的，只有营收增速弱有效。**真正有效的核心是技术面"回踩买点"（v3 已证 5 日胜率 59%）**。v6 的最终权重 = 技术 100 主导 + 营收/反向资金面辅助。

### 方法论文档（踩坑）
1. **事件型因子不能用时间序列 IC 法**：预告/财务是"公告日"事件，必须用事件研究法（按公告日对齐未来收益），不能用融资余额那种按月采样。
2. **必须用超额收益而非绝对收益**：预告历史横跨 24 年（2002~2026），混入 2007/2015 牛市顶 + 2008/2018 熊市，绝对收益被系统性拉低，必须减同期沪深300。
3. **限定近 N 年**：陈旧预告/财报对当下选股无指导意义，回测限定 2023 年以来（财务回测放宽到 2015）。
4. **`kline_time` 带时分**：`query_kline` 个股日K的 `kline_time` 是 `"20250110 00:00:00"`，需 `.split()[0]` 再转 int；但指数日K（000300.SH）是标准 `2021-01-04` 格式，两者解析不同，统一 `.split()[0].replace("-","")`。
5. **财报"未来函数"陷阱**：财务因子值不能用报告期末日对齐收益（市场那时还看不到），必须用公告日 `ANN_DATE`/`ANN_DT` 对齐。
6. **同比增速极端值污染**：净利增速出现 -17448%、筹码环比 2403175% 等脏数据（去年净利≈0 导致增速爆炸），必须清洗（同比>±200% 截断剔除）。
7. **`get_income` 多口径**：`STATEMENT_TYPE` 有 9 个取值，只取 `"1"`（合并标准口径），否则同比错乱。
